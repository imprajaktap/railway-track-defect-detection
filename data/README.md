# Data Directory

This directory stores dataset assets for the railway-track defect detection project.

## Structure

- `raw/` — Original dataset files, kept unchanged where possible.
- `processed/` — Prepared images, converted annotations, and derived data used by experiments.
- `sample/` — Small sample assets for development or demonstration.

## Dataset Handling

1. Record the dataset source, access date, license or usage terms, and class definitions.
2. Keep original dataset assets in `raw/` and avoid modifying them in place.
3. Place derived/preprocessed assets in `processed/`.
4. Do not commit large datasets or restricted assets to GitHub. See `.gitignore`; use external storage or documented download instructions when needed.
5. Do not place railway footage or collect data by entering tracks or restricted railway infrastructure.
