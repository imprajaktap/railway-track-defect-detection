# Notebooks

Jupyter notebooks for exploratory analysis, preprocessing experiments, training, and evaluation.

## Suggested order

1. `01_dataset_exploration.ipynb` — inspect dataset folders, image dimensions, labels, and class distribution.
2. `02_preprocessing.ipynb` — review preprocessing and augmentation samples.
3. `03_model_training.ipynb` — train or fine-tune the detector.
4. `04_model_evaluation.ipynb` — evaluate test results and conduct error analysis.

Keep notebooks reproducible, avoid committing large datasets or model weights, and do not report metrics until experiments have been run.
